# P2 review and appearance changes — 2026-10-14

This batch implements the P2 items from the customer audit: dark-mode hierarchy, usable document previews, clearer counts, and guidance for choosing an export. The Paper & Ink light palette and document paper appearance are retained.

## Behavior

- Night Studio gives the primary camera scan an amber background. Secondary actions, navigation, outlines and muted text use explicit blue-gray theme colors.
- Review opens with larger page previews in a grid. Grid/list choice persists across documents and restarts. List view retains drag reordering; both views provide labeled up/down controls and inclusion checkboxes. Editing remains available by tapping a preview.
- Included pages have an amber border; excluded pages explicitly say they are excluded from export. Recognition and number-review status remain visible.
- Repeated processing notes move into **Capture details**, grouped by note with page numbers. Capture warnings remain visible above the previews and are available in the details as well. The instructions explain editing, exclusion and reordering.
- Review uses lazy page widgets with bounded thumbnail decoding. At larger text sizes it uses one grid column; short screens and text over 160% put the import/export controls in the same scrollable flow. The processing screen also scrolls when needed. This prevents fixed controls from overflowing a small screen.
- Page, unread-page, export and review-line counts use singular/plural copy. P1 already added the editor's safe-area spacing.
- Each export explains the customer task it suits. Searchable scans keep the page image and add recognized text. Digital text layout can change spacing and Nepali text selection; its guidance recommends searchable scans when preserving the original layout matters. Editable DOCX, plain text, Markdown and correction JSON have separate explanations. Text exports still recognize unread selected pages and retain existing corrections.

## Verification

- `flutter test`: 22 tests passed, including all P1 regression tests. New checks cover grid/list persistence, selection and order preservation, grouped notes, export guidance, editor navigation, both themes at 360×800 and text sizes 100%/160%, a 320×720 screen at 200% text, and lazy review of 150 unread pages.
- The 200% text test initially found a real vertical overflow; the scrolling changes above resolve it and the export picker is reachable.
- `flutter analyze`: no issues found.
- `flutter build apk --release --split-per-abi --target-platform android-arm64,android-x64`: both APKs built. Signatures verify with the existing Android development certificate; neither manifest requests Internet permission.
- Installed the final x86_64 release on the Android 15/API 35 emulator while disconnected. Observed the amber dark Home, both themes' page previews, grid/list persistence after reopening, exclusion, arrow reordering, and actual drag reordering. Preview taps open the editor; its bottom action sits above Android navigation.
- Generated a searchable PDF from the four-page smoke document with one page excluded. `pypdf` confirms three pages and English/English/Nepali text in the selected order. Android's share sheet opens; it was cancelled without sending the file. Extraction joins the first English heading's two words, so this verifies content/order rather than exact whitespace fidelity.
- With Android `font_scale=2.0`, review becomes one column and its import/export controls remain reachable by scrolling. The export picker opens and its longer descriptions scroll. Restored the original `font_scale=1.0`. Android uses nonlinear font scaling; the separate widget check uses linear 200% at 320×720.
- The release-process log contains no RenderFlex overflow, unhandled exception or fatal exception during these checks. This is smoke evidence, not exhaustive device qualification. P1's full native integration suite was not repeated for this UI batch; its automated regression coverage passed above.
- Deleted the temporary smoke document through the app. All 36 original library files retained their hashes. Restored the pre-P2 data snapshot and verified all 166 document/preference files against their original hashes; the original four library documents and appearance preference are retained.
