# P3 typography and selection polish — 2026-10-16

P3 completes the two remaining visual-polish items from the customer audit. It does not add scanning or export features.

## Changes

- Home and Settings use the intended **Instrument Serif** display font through shared theme styles, replacing Android's generic serif fallback. Both appearances use the same font, sizes and layout. Body text, controls, document names and Devanagari retain **Mukta**.
- The Latin display font is bundled locally, so first launch and later use require no font download. The existing web font at `webapp/frontend/public/fonts/instrument-serif-400.woff2` was decompressed to TTF with FontTools 4.60.1; glyphs and font naming were retained. Its 48,360-byte TTF covers the English display headings. The bundled SIL Open Font License and original copyright notice are in `assets/InstrumentSerif-OFL.txt`. This conversion adds no runtime dependency.
- Navigation destinations, folder filters and grid/list controls share amber selected backgrounds with dark foregrounds. Editor tabs use an amber underline and a stronger, readable selected label. Unselected controls use the theme's supporting text color.
- Appearance, OCR-language and book-layout dropdowns show an amber checkmark for the current option, including selected semantics. The language marker refreshes immediately after a change. Dropdown focus highlights use the amber palette. Existing Material interaction and disabled states remain in use; disabled grid/list-style buttons do not receive the selected amber fill.

## Verification

- Full suite: `flutter test --no-pub --concurrency=1`, **22 passed**, including P1/P2 regressions.
- Updated narrow-phone checks exercise both themes, heading/body font roles, folder selection, persisted language changes and current-option markers. Contrast checks verify at least 4.5:1 for selected foregrounds and editor-tab labels in both palettes, including the disabled selected-icon case.
- `flutter analyze --no-pub`: **no issues found**.
- `flutter build apk --release --split-per-abi`: both release APKs compiled with development keys.
- Signed-package verification: `apksigner` verifies APK signatures; `aapt dump permissions` confirms `android.permission.INTERNET` is absent; `assets/InstrumentSerif-Regular.ttf` is present in both APKs and matches local bytes; `FontManifest.json` includes `Instrument Serif`.
- Installed the final x86_64 release on the Android 15 / API 35 emulator (`emulator-5554`) while disconnected (`dumpsys connectivity` confirms `Active default network: none`).
- Verified typography in both themes: Home heading (*From paper to possibility.*) and Settings heading (*Make yourself at home.*) render with Instrument Serif, while body text and controls use Mukta.
- Verified selection controls:
  - Navigation bar displays amber active indicator with dark foreground.
  - Folder chips display amber selected fill and dark foreground ("Study" / "All").
  - Review toolbar grid/list toggles show amber selected pill and dark icon.
  - Page editor tabs ("Image" / "Text") show amber indicator bar and high-contrast active label.
  - Dropdown menus (Appearance, OCR language) display circled amber checkmark for active option with accessibility `selected` state and instant refresh on change.
- Release logcat confirms zero crashes, zero unhandled exceptions, and zero RenderFlex layout overflows.
